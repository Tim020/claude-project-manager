9Project assistant: notes first, plan by approval, skills when it has earned one

One assistant per project, opened from the left rail next to Sessions and Pull Requests. Notes save straight away, whoever writes them, and anything the assistant adds can be undone. Plan items and skills only change when you approve them. A note becomes a plan item when you promote it, so the plan grows out of your notes. Starting a session from a plan item opens it with the item, its notes and the skills the assistant picks. Chat is there when you ask for it, but it isn't the main way in.
