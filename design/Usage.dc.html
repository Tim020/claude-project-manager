11Usage: cost, tokens and plan share per session, folder and project

Claudio adds up the token counts in each session's transcript and prices them at API rates. On a plan that's an estimate (est.), since plans aren't charged per token. A session's usage shows its all-time figures on the right rail, under a new Usage tool. Projects and folders get a new left-rail tool, Usage (⌘4), with ranges of 24h, 7d, 30d, All or custom dates. The status-bar usage figures now open a popover with an Open Usage Window link, which goes to the Usage window: every project, plan limits, and the assistant's own section. 11a is chosen: tabs stay for session things only. 11b is kept for reference. The handover is in Usage Handover.md. Rows, tabs, ranges, rails, the panel states and the status-bar figures are all clickable.
